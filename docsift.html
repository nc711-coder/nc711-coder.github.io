DocSift: AI document extraction

Turns invoices, receipts and W-9s (PDFs, scans or phone photos) into clean, checked data.

Try the live demo →Source code on GitHub

What it does

  • Reads clean PDFs, scans and phone photos (finds the page, straightens it, OCR)
  • Checks every value against the page and the math before approving
  • Sends anything doubtful, like a possible duplicate, to a person with the exact reason
  • Masks tax IDs and card numbers; originals are deleted after 24 hours
  • In testing on 60 documents, 100% of auto-approved documents were correct

Built with

Python, FastAPI, Tesseract OCR, OpenCV, an open-weight LLM with structured output, n8n, Google Sheets, Google Cloud Run.

Try the built-in synthetic samples; please don't upload real documents. The demo may take a few seconds to wake up on the first visit.
